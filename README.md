Overview

Fraud Prediction ML Project is a Machine Learning application that detects fraudulent financial transactions. The project uses historical transaction data to train classification models and predict whether a transaction is fraudulent or legitimate.

This project demonstrates the complete Machine Learning workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and prediction.

🚀 Features
Data Cleaning and Preprocessing
Exploratory Data Analysis (EDA)
Feature Engineering
Handling Imbalanced Data
Multiple Machine Learning Models
Model Evaluation and Comparison
Fraud Prediction on New Transactions
Visualization of Results
